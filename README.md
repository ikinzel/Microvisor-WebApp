# Microvisor-WebApp

## Project URL

* [Landing page](http://a25sewt104.studev.groept.be)

## Implemented Features

* User registration and login with session-based authentication
* Logout functionality
* Forgot password flow with email-based reset link
* Home dashboard showing daily nutrient progress
* Food intake logging: manually search and add food items using the USDA nutrient database
* Food intake management: edit or delete existing food entries
* Receipt scanning: upload a photo of a receipt to automatically extract and import food items via OCR
* Blood test PDF upload: upload a blood test report and automatically extract result values
* Blood test results overview: view and track historical blood test results
* Health conditions management: select and manage personal health conditions
* User profile page: update personal information
* Profile photo upload
